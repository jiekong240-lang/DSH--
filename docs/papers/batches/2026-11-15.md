## 新增条目（7）

### 1. Folio: Recoverable Multi-Resolution Context Folding for Long-Horizon Language Agents

- **链接**：https://arxiv.org/abs/2611.16627
- **对应缺口**：长程任务与检查点续跑 / 跨会话记忆与状态携带
- **一句话技术作用**：把 resume-task 的上下文管理从「模型再写一遍摘要」改成运行时多分辨率折叠加句柄恢复，既降成本又避免关键工具结果被摘要丢掉。
- **要点**：运行时并行记录三层历史：模型随回复写下的短轮次笔记（L1）、事件清单（L2）和原始源记录（L3），按龄级程序化折叠并留下可翻页检索的句柄。75 道 LOCA-bench、同一 DeepSeek-V4-Pro 骨干下做成 66 题，对照同运行时模型摘要压缩 54 题，以及 Claude Code / Codex / SoL-Pi 的 49–59 题；工作时间约减半，成本约为该对照运行时的 1/2.4，单次折叠中位 0.6 秒。
- **标签**：检查点续跑, 上下文折叠, 长程agent

### 2. When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents

- **链接**：https://arxiv.org/abs/2611.14326
- **对应缺口**：跨会话记忆与状态携带 / 多轮工具规划与自我纠错
- **一句话技术作用**：给 DSH 持久记忆加写入闸门：经验先当假说做迁移/证伪/回归探针，通过才入库，避免把偶发成功或有害策略写进跨会话状态。
- **要点**：FGSE 把候选经验写成带前置条件、行为改动、预期效果和验证器的假说，先只在临时状态应用，再按实测增益与风险决定提交、修订或拒绝。WebArena 成功率 39.8，AppWorld 平均完成 78.8，τ-Retail/τ-Airline Pass@1 为 0.724/0.487；证伪失败 5.0%，回归损伤 1.3%，有害已提交更新 3.6%。
- **标签**：跨会话记忆, 证伪门控, 自我演化

### 3. GroundCascade: Selective Second Opinions for GUI Grounding

- **链接**：https://arxiv.org/abs/2611.13177
- **对应缺口**：成本约束下的级联路由（少钱也要把任务跑完）
- **一句话技术作用**：给 free-ladder 的点击定位提供训练免费路径：全屏与放大一致就走快路径，不一致才请第二意见，在少调用强模型的前提下抬升 grounding 完成率。
- **要点**：免训练控制器用同一 grounder 全屏/放大预测的一致性决定是否升级互补模型。ScreenSpot-Pro 上 Indeed-UI-32B/8B/32B 达 85.33%，可见目标 OSWorld-G-Refined 上 Qwen3.6-27B/3.8-27B/3.8-27B 达 88.43%，分别比更强的两遍单模型高 2.66 与 2.35 个百分点；UI-Vision 类别均衡准确率 72.20%。Full 模式每请求 2.42–2.73 次调用，比无条件双模型两遍少 31–39%。
- **标签**：成本路由, GUI grounding, 级联二次意见

### 4. Keeping LLM Agents on Procedure: Executable Finite-State Control for Long-Horizon Instruction Fidelity

- **链接**：https://arxiv.org/abs/2611.10884
- **对应缺口**：长程任务与检查点续跑 / Windows与进程编排、可靠取消
- **一句话技术作用**：把程序性长任务的状态机放进运行时而非上下文：只靠重述或 resume 修不了漂移；用 FSM 卡住工具调用与回合结束，让小模型也能把 SOP 跑完并降低成本。
- **要点**：可执行有限状态机把工作流状态放在模型上下文之外，在工具调用、状态转移和回合结束三处强制执行。预注册 200 账户 SOP-Bench 上，Claude Haiku 4.5 配 FSM 平均按规程正确处理 139 个账户，最强基线为 48（差值 95% CI [46, 130]），且该速率维持到批次结束。带 FSM 的 Haiku 4.5 平均正确决策数超过 plain Claude Sonnet 4.6，成本仅为其 38%。
- **标签**：长程SOP, 可执行FSM, 过程编排

### 5. OS-Wizard: Scaling Computer-Using Agents to Specialized Software via Knowledge-Guided Exploration

- **链接**：https://arxiv.org/abs/2610.33907
- **对应缺口**：仓库/项目自动理解与 execution bootstrap / 长程任务与检查点续跑
- **一句话技术作用**：给 DSH 打开 FreeCAD 等专用软件提供「教程+原生命令+关键态快照分叉」的轨迹采集与续跑路径，而不是只靠线性 GUI 点击摸索。
- **要点**：教程引导探索，混合 GUI–Code 动作空间直接执行应用原生命令，并在关键状态做检查点、从最近快照回放以分叉探索。共 10,919 条自动验证轨迹。微调 Qwen3.5-27B 后，ScienceBoard 成功率从 5.9% 升到 64.1%，超过报告的人类总体 59.8%；同等 10K 样本预算下为 36.5%，高于 Task-driven 13.0% 与 Branch-driven 18.9%。OSWorld 上仅用 GUI 动作从 39.1% 升到 42.9%。
- **标签**：execution bootstrap, 专用软件CUA, 检查点探索

### 6. CARE-PO: Controllable Tool-Call Efficiency for LLM Agents

- **链接**：https://arxiv.org/abs/2611.12125
- **对应缺口**：成本约束下的级联路由（少钱也要把任务跑完）
- **一句话技术作用**：给 free-ladder / quota-probe 提供可调的工具调用预算：按任务难度固定锚点，一次训练得到效率与能力两个工作点，避免为省钱训成不调用工具、任务做不完。
- **要点**：效率奖励的锚点在训练前按任务难度固定，并向每个在线 GRPO 组注入一条已成功轨迹，抑制「零工具调用」坍缩。GAIA 上三个规格共六个工作点中有五个同时优于基座的成功率与调用次数；四个留出多跳基准上，27B 与 4B 能在更少调用下保住或提高成功率，9B 则用成功率换更少调用。三种规格训练过程中调用次数均明显高于零。
- **标签**：成本路由, 工具调用效率, 可控工作点

### 7. AgentHorizon: Evaluating Agentic Judges for Long-Horizon Computer-Use Tasks

- **链接**：https://arxiv.org/abs/2610.11050
- **对应缺口**：轨迹级声称-vs-做成评测
- **一句话技术作用**：给 claim-gate / lookout 提供长程跨系统、带配对负例的法官尺子：不能只看轨迹像不像做完，而要能找出隐藏证据，拒绝「做的是另一件事」的假绿。
- **要点**：1,373 条计算机使用任务（指令–轨迹对），来自三操作系统上 166 小时真人录制；用相近指令互换构造负例。评测 11 个法官：直接喂最多 300 张截图的完整轨迹，或把它们当作编码 agent 放进五种 harness。最强 agentic 法官 GPT-5.5 在 AH 子集上平衡准确率 80.9%；工具使用对部分模型有帮助，却会降低开源权重模型，且各法官在「接受真成功 / 拒绝失败」上差异很大。
- **标签**：声称vs做成, 长程评测, agentic法官
