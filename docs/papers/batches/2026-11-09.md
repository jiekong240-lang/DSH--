## 新增条目（10）

### 1. ScaleCUA: Scaling Open-Source Computer Use Agents with Cross-Platform Data

- **链接**：https://arxiv.org/abs/2509.15221
- **对应缺口**：任务完成率评测尺子 / 跨平台桌面执行
- **一句话技术作用**：给 stage1/瞭望定外部完成率基线，并提供 Windows 端可对标数字。
- **要点**：跨平台大规模 CUA 数据与开源模型；OSWorld-G 60.6%、WebArena-Lite-v2 47.4%，含 WindowsAgentArena 结果。
- **标签**：CUA完成率, 跨平台数据, Windows

### 2. Surfer 2: The Next Generation of Cross-Platform Computer Use Agents

- **链接**：https://arxiv.org/abs/2510.19949
- **对应缺口**：多轮工具规划与自我纠错 / 长程失败恢复
- **一句话技术作用**：可直接对照 DSH agent-loop：规划与执行解耦 + Validator 再决策，对齐 supervisor 续跑。
- **要点**：纯视觉跨端 CUA：Orchestrator/Navigator/Validator；自验证+自适应恢复；OSWorld 60.1%。
- **标签**：规划执行分离, 自我验证, 长程恢复

### 3. GUI-PRA: Process Reward Agent for GUI Tasks

- **链接**：https://arxiv.org/abs/2509.23263
- **对应缺口**：长程任务过程监督 / 跨轮上下文压缩
- **一句话技术作用**：为长桌面轨迹提供步级奖励与记忆压缩思路，减轻 stage1 长链路假绿与漂移。
- **要点**：GUI 过程奖励 Agent：相关检索+递进摘要抗 lost-in-the-middle；自适应 UI 感知；在线基准成功率+14.53%。
- **标签**：过程奖励, 长程GUI, 动态记忆

### 4. AgentRewind: Recoverable Execution for Long-Horizon LLM Agents

- **链接**：https://arxiv.org/abs/2608.14380
- **对应缺口**：长程任务与检查点续跑（resume-task 升级）
- **一句话技术作用**：把 resume-task 从只读简报升级成「上下文+环境」可回退状态机的直接蓝图。
- **要点**：对齐记录 agent 上下文与受控环境检查点，支持回退并注入 rewind memory；配 MettleBench。
- **标签**：检查点续跑, 长程恢复, 工程任务

### 5. SPROUT: Scaling Agentic Reinforcement Learning for Long-Horizon Software Engineering

- **链接**：https://arxiv.org/abs/2610.14405
- **对应缺口**：仓库级长程编码续跑 / execution bootstrap
- **一句话技术作用**：服务 DSH sandbox 编程闭环：失败后从中间快照分支，而不是整任务重开。
- **要点**：每轮快照文件系统+agent 上下文，验证器引导回溯分支；长程编码 pass@k 提升且省 token。
- **标签**：快照分支, 编码Agent, 检查点

### 6. AgentRouter: Heterogeneous Model Routing for Cost-Optimal Multi-Step Agentic Workflows

- **链接**：https://arxiv.org/abs/2609.22951
- **对应缺口**：成本约束下的级联路由（free-ladder/quota）
- **一句话技术作用**：给 free-ladder / quota-probe 提供「按步选档」而非整会话绑死大模型的算法依据。
- **要点**：轨迹步级异构模型路由（12M 分类器）；成本降 71.8% 且保留 97.3% 任务质量。
- **标签**：成本路由, 步级级联, agent工作流

### 7. xRouter: Training Cost-Aware LLMs Orchestration System via Reinforcement Learning

- **链接**：https://arxiv.org/abs/2510.08439
- **对应缺口**：成本约束下的级联路由
- **一句话技术作用**：对齐「少钱也要把活跑完」奖励塑形：无成功无奖，成功则惩罚多余花费。
- **要点**：把路由当带经济约束的决策；成功才给奖、成功后越便宜越好；可直答或委派外部模型。
- **标签**：成本感知RL, 级联路由, 编排

### 8. Who Verifies the Agent's Success Claim? Self-Report Leakage in GUI-Agent Completion Judging

- **链接**：https://arxiv.org/abs/2610.29609
- **对应缺口**：轨迹级声称-vs-做成评测
- **一句话技术作用**：直接支撑 stage1-accept / claim-gate / lookout「截图不作判据」：报告不得进入轨迹判定。
- **要点**：报告-轨迹审计：隔离自报可显著提高危险误报召回；结构化证据-策略审计器反假绿。
- **标签**：声称vs做成, 轨迹审计, 反假绿

### 9. EchoPath: Execution-Level Replayable Memory for GUI Agents

- **链接**：https://arxiv.org/abs/2609.16635
- **对应缺口**：跨会话记忆与状态携带
- **一句话技术作用**：把 memory-drive / session 召回从「再推理」升级成可参数化、可门控重放的执行资产。
- **要点**：把经验证 GUI 轨迹打成可调用记忆（类 MCP）；视觉重瞄准重放；中位 token 成本降 90%+。
- **标签**：可回放记忆, 跨会话, GUI

### 10. UFO2: The Desktop AgentOS

- **链接**：https://arxiv.org/abs/2504.14603
- **对应缺口**：Windows/进程编排与可靠取消
- **一句话技术作用**：家用 Windows 上跑 CUA 的会话隔离与进程协调参考，对齐维护脚本与可靠取消边界。
- **要点**：Windows Desktop AgentOS：RDP 环回 PiP 会话、输入隔离、Host/AppAgent、私有状态+共享黑板。
- **标签**：Windows编排, 会话隔离, 进程协调
